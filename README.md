# RFID System Design

This project is a custom PCB designed for a potential RFID-based key fob system.

The PCB incorporates a planar spiral coil, electronic components, switches and connections for a display. The project focuses on applying electronic circuit design and PCB layout principles.

---

## How It Works

The system is designed around a PCB spiral coil that may be used for inductive communication with RFID tags or key fobs.

The PCB design includes:

- **Spiral Coil** – A PCB-integrated coil intended for inductive signal transmission or reception.
- **Electronic Circuitry** – Components and connections for processing electrical signals.
- **Battery Holder** – Provides a connection for a coin-cell battery.
- **Switches** – Allow user interaction with the circuit.
- **Display Connections** – A footprint for connecting an LCD display.
- **Test Points** – Allow electrical measurements and circuit testing.

---

## PCB Design

The project involved:

- Designing the PCB layout.
- Placing electronic components and footprints.
- Routing electrical connections between components.
- Creating a planar spiral coil.
- Using copper layers and ground regions.
- Producing a physical PCB prototype.
